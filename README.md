# Subnautica-PDA-Keyboard-Project
We have developed a shortcut macropad for every day use with the look and feel of the iconic PDA used throughout any playthrough of Subnautica. 
The idea is a 20 key macropad that is programmed to take you to useful platforms like google drive, youtube, calendar apps, and more. You keep it in your hand and when a specific key is pressed, it will take you to a specific platform just like a regular shortcut would. Our project is inspired by popular streamdecks like Elgato, but with our own unique twist; the fact that it looks like it's straight out of planet 4546-B.
This is for the Hackclub Fallout competition, and we decided to create it because we all love Subnautica and actually useful electronics and we wanted a way to combine the two in a way that was still useful, so we landed on a keyboard. While a normal keyboard is great, the 104 keys present on a standard keyboard would be hard to cram into the model we've come up with and would make it crowded and bulky so we decided on a macropad which is a lot smaller and we specified it into one that is entirely for shortcuts, kept separate from a typical keyboard you use to type with. Our idea was that the macropad could be kept off to the side of a desk and held in one hand for convenience so your desk isnt cluttered from a whole separate keyboard lying around. We felt that a handheld style worked best because it keeps true to the original function of the PDA in Subnautica, as well as being easier to store and use.
